## 📖 عن المشروع

**HESIN** هو مستودع معرفي ضخم يحتوي على منظومة متكاملة من المفاهيم الإسلامية المنهجية المستخلصة من دروس العلامة **السيد/ حسين بدر الدين الحوثي** (رحمه الله). يمثل المشروع قاعدة معرفية منظمة على شكل **أنطولوجيا دلالية** (Semantic Ontology) تربط بين المفاهيم القرآنية والعقدية والتربوية عبر علاقات منطقية وسببية.

### 🎯 الرؤية

> تحويل الخطاب الديني من "نقل معلومات" إلى "بناء منهج استدلالي" يمكن للباحثين والمطورين استخدامه في التحليل الآلي والاستدلال المنطقي.

### 🎯 الأهداف

- 📚 توثيق التراث المعرفي الإسلامي بشكل منظم وآلي
- 🔗 بناء شبكة مفاهيمية مترابطة تسهل الفهم والاستدلال
- 💡 تمكين الباحثين والطلاب من الوصول للمعرفة بشكل منهجي
- 🤖 توفير قاعدة معرفية قابلة للاستخدام في الأنظمة الذكية والذكاء الاصطناعي
- 📊 تحليل الخطاب الديني بمنهجية علمية دقيقة

## 🔗 أنواع العلاقات في الأنطولوجيا

### العلاقات الهيكلية (Structural)

| النوع | الوصف | مثال |
|-------|-------|-------|
| **يؤسس لـ** | بناء مفهوم جديد على أساس مفهوم سابق | الإيمان ← العمل الصالح |
| **ينبني على** | الاعتماد المنطقي على مفهوم تأسيسي | العمل الصالح ← الإيمان |
| **جزء من** | العلاقة التركيبية بين المفاهيم | الصلاة ← جزء من الإيمان |
| **نوع من** | التصنيف والتفريع المفاهيمي | العلم النافع ← نوع من العلم |
| **أخص من** | التخصيص الدلالي | التضليل الإعلامي ← أخص من التضليل |

### العلاقات السببية (Causal)

| النوع | الوصف | مثال |
|-------|-------|-------|
| **يسبب** | العلاقة السببية المباشرة | قلة المعرفة ← تسبب ← ضعف الإيمان |
| **يؤدي إلى** | النتيجة المترتبة على المفهوم | الإعراض ← يؤدي إلى ← قسوة القلب |
| **يمنع** | العلاقة النافية المانعة | القرآن ← يمنع ← الجمود |
| **يضاد** | التضاد والتناقض المنطقي | الإيمان ← يضاد ← النفاق |

### العلاقات المنهجية (Methodological)

| النوع | الوصف | مثال |
|-------|-------|-------|
| **وسيلة لـ** | الأدوات والوسائل لتحقيق غاية | الاجتماع الموحد ← وسيلة لـ ← الموقف الموحد |
| **شرط لـ** | الشروط اللازمة لوجود المفهوم | الإخلاص ← شرط لـ ← قبول العمل |
| **ينفي** | النفي والإبطال المنهجي | السمع والطاعة ← ينفي ← المنّ على الله |
| **يتداخل مع** | التداخل والترابط الدلالي | الثقافة القرآنية ← تتداخل مع ← المناعة الفكرية |

## 🎓 المجالات المعرفية المغطاة

### 1️⃣ العقيدة والتوحيد
```
• معرفة الله وأسمائه الحسنى
• الإيمان واليقين والتوكل
• الآخرة (الجنة، النار، البعث، الحساب)
• القضاء والقدر والحكمة الإلهية
• تنزيه الله عن صفات المخلوقات
```

### 2️⃣ المنهجية القرآنية
```
• القرآن ككتاب هداية ومنهج حياة
• التدبر والتفكر في الآيات
• فهم النصوص: المحكم والمتشابه
• التعامل مع الروايات والأحاديث
• حفظ القرآن الإلهي من التحريف
```

### 3️⃣ التربية والسلوك
```
• الهوية الإيمانية والشخصية الرسالية
• تزكية النفس والخشوع في العبادة
• الأخلاق والآداب الإسلامية
• الصبر والاستقامة والثبات
• الدعاء المقترن بالعمل
```

### 4️⃣ التحليل السياسي والحضاري
```
• دراسة بني إسرائيل كمرآة للواقع
• تحليل مخططات الأعداء (اليهود، أمريكا)
• الصراع الحضاري والمواجهة الاستراتيجية
• الجهاد القرآني والمقاومة المشروعة
• نقد الأنظمة والحكام المنحرفين
```

### 5️⃣ النقد المنهجي
```
• نقد التراث والتفاسير المنحرفة
• نقد علم الكلام ومنهج الاستدلال
• نقد المناهج الفقهية المجزئة
• كشف الشبهات والرد عليها منهجياً
• نقد الوسطية المشوهة وثقافة الصمت
```

## 🔧 كيفية الاستخدام

### للباحثين والطلاب (Python)

```python
import json

# تحميل ملف المفاهيم
with open('مفاهيم سلسلة دروس معرفة الله.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# البحث عن مفهوم محدد بالمعرف
concept = next(
    (c for c in data['concepts'] if c['concept_id_placeholder'] == 'C001'), 
    None
)
if concept:
    print(f"📌 المفهوم: {concept['name']}")
    print(f"📝 التعريف: {concept['definition']}")
    print(f"🔗 المرادفات: {', '.join(concept['synonyms'])}")
    print(f"⭐ الأهمية: {concept['importance']}")

# استخراج جميع المفاهيم الرئيسية
core_concepts = [
    c for c in data['concepts'] 
    if c['importance'] == 'رئيسي'
]
print(f"\n✅ عدد المفاهيم الرئيسية: {len(core_concepts)}")

# البحث عن الآيات المرتبطة بمفهوم
target_concept = 'C001'
related_verses = [
    v for v in data['verses'] 
    if target_concept in v['related_concept_placeholders']
]
for verse in related_verses:
    print(f"📖 {verse['surah']}:{verse['verse_number']} - {verse['verse_text']}")
```

### للمطورين (JavaScript)

```javascript
// تحميل البيانات
const data = require('./مفاهيم سلسلة ملازم المدرسة.json');

// استعلام عن السلاسل السببية لمفهوم معين
const getCausalChains = (conceptId) => {
  return data.causal_chains.filter(chain => 
    chain.steps.some(step => step.concept_id_placeholder === conceptId)
  );
};

// الحصول على جميع العلاقات الصادرة من مفهوم
const getOutgoingRelations = (conceptId) => {
  return data.relations.filter(rel => 
    rel.source_concept_id_placeholder === conceptId
  );
};

// تحليل مجموعة مفاهيمية
const analyzeGroup = (groupName) => {
  const concepts = data.concepts.filter(c => c.group_name === groupName);
  return {
    count: concepts.length,
    core: concepts.filter(c => c.importance === 'رئيسي').length,
    secondary: concepts.filter(c => c.importance === 'فرعي').length,
    peripheral: concepts.filter(c => c.importance === 'هامشي').length
  };
};

// مثال على الاستخدام
console.log(analyzeGroup('مجموعة النظرة المتكاملة للدين'));
```

### استعلامات مفيدة (SPARQL-style Pseudo)

```sparql
# جميع المفاهيم المرتبطة بآية معينة
SELECT ?concept WHERE {
  ?verse :verseNumber 7 .
  ?verse :relatedTo ?concept .
}

# السلاسل السببية التي تبدأ بمفهوم محدد
SELECT ?chain WHERE {
  ?chain :firstStep "C001" .
  ?chain :hasSteps ?steps .
}

# المفاهيم التي لها علاقة "يسبب" مع مفهوم آخر
SELECT ?source ?target WHERE {
  ?source :relationType "يسبب" .
  ?source :targets ?target .
}

# جميع الآيات في سورة المائدة
SELECT ?verse WHERE {
  ?verse :surah "المائدة" .
}
```

[عدم الانطلاق في طاعة الله]

📊 التحليل:
• نقطة التدخل: تعزيز معرفة الله
• المخرج: التوبة والعودة للقرآن
• النتيجة المتوقعة: استعادة الثقة والنصر

### مثال 3: تحليل مجموعة مفاهيمية

```
🗂️ المجموعة: منهجية التعامل مع القرآن

المفاهيم الرئيسية (7):
├── القرآن كتاب عملي متحرك
├── الهدى بالقرآن
├── اتباع القرآن
├── الموقف العملي من القرآن
├── نصرة الله
├── ثقافة القرآن
└── نيل الرحمة

العلاقات الداخلية:
• القرآن العملي ← يؤسس لـ ← اتباع القرآن
• اتباع القرآن ← يسبب عن ← نيل الرحمة
• الهدى بالقرآن ← يؤسس لـ ← الموقف العملي

التطبيق:
✓ أي تحليل للواقع يجب أن ينطلق من القرآن
✓ القرآن مرجع في كل حدث معاصر
✓ عدم الفصل بين النص والتطبيق
```
